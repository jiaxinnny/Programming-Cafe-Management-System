# Programming-Café-Management-System

## 📖 Overview
This project used C language to build a system called "Programing Café". This system is to offer extra coding sessions for students. There are 3 types of user using this sytem which are Admin, Tutor, and Student. 

## 🎯 Key Focus Areas (Users' Functional features)
* Admin - Add new user, Add new session, View all users, Enrol student in a session
* Tutor - View their own timetable with sessions assigned to them
* Student - View their timetable, Enrol themselves in any available session
